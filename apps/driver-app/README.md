# تطبيق السائق — اللوجستر

تطبيق ويب مستقل موجّه للسائقين، منفصل عن تطبيق المكاتب التشغيلية وعن تطبيق المستودعات. يستخدم واجهات Laravel الموجودة تحت `/api/v1/driver`، ويترك صلاحيات الوصول وقواعد انتقال الحالات للخادم.

## ما يتضمنه هذا الإصدار الأولي

- تسجيل الدخول باستخدام Sanctum API token.
- اختيار ملف السائق عند ارتباط الحساب بأكثر من ملف نشط.
- لوحة مختصرة لمهام السائق وحالاتها.
- قائمة مهام مع فلترة بالحالة والبحث داخل الصفحة الحالية والتنقل بين صفحات API.
- تفاصيل المهمة والشحنة والموقع والمستلم والرحلة.
- سجل أحداث المهمة.
- إرسال تحديثات الحالة: التوجه، الوصول، الإكمال، أو تعذر التنفيذ، مع حقول الإثبات واسم المستلم وسبب التعذر حسب قواعد الخادم.
- بدء الوردية وإنهاؤها، واختيار مركبة، وفحوص ما قبل/بعد الوردية وقراءة العداد.
- واجهة عربية RTL متجاوبة للجوال وسطح المكتب.

## التشغيل محليًا

```powershell
cd apps/driver-app
Copy-Item .env.example .env
npm install
npm run dev
```

اضبط `VITE_API_BASE_URL` في ملف `.env` لعنوان API الذي يمكن للمتصفح الوصول إليه. القيمة الافتراضية هي `http://127.0.0.1:8000/api/v1`، وهي مناسبة فقط عندما يكون الخادم متاحًا على نفس جهاز المتصفح. يجب ضبط CORS في Laravel لعنوان واجهة التطبيق.

## البناء

```powershell
npm run build
```

## تنبيهات قبل الإنتاج

- هذا أساس تشغيلي أولي وليس منتجًا مكتملًا أو منشورًا.
- مرجع `proof_reference` ليس رفعًا للصورة أو توقيعًا. استخدم خدمة رفع الأدلة الخاصة الموثقة في واجهة API قبل الاعتماد على الإكمال الميداني؛ لا تدخل مرجعًا وهميًا.
- لا توجد مزامنة offline أو إشعارات push أو التقاط GPS تلقائي في هذا الإصدار.
- يجب التحقق من نجاح CI واختبارات الاستخدام الفعلي قبل الدمج والنشر.
- صلاحيات السائق تُفرض في Laravel؛ إخفاء الأزرار في الواجهة ليس بديلًا عن تفويض الخادم.
