# اللوجستر — تطبيق السائقين

واجهة مستقلة للسائقين، منفصلة عن لوحات المكاتب والمستودعات وإدارة الأسطول. هذه الواجهة تتصل بواجهات API الموجودة في Laravel ولا تنشئ حسابات سائقين أو تعيّن المهام بنفسها.

## المتطلبات

- Node.js 20.19+ أو 22.12+
- تشغيل API الخاص باللوجستر مع Sanctum وقاعدة البيانات مجهزة.

## التشغيل

```powershell
cd apps/driver-app
npm install
$env:VITE_API_BASE_URL="http://127.0.0.1:8000/api/v1"
npm run dev
```

افتح العنوان الذي يعرضه Vite. غيّر `VITE_API_BASE_URL` إلى عنوان API الفعلي عند الحاجة.

## الوظائف المتصلة بالـ API

- تسجيل الدخول والخروج.
- ملف السائق والملفات المرتبطة بالحساب.
- ملخص المهام وقائمة المهام مع تصفية الحالة والنوع.
- تفاصيل المهمة وسجل الأحداث.
- الانتقال بين الحالات المسموحة.
- رفع إثبات التسليم الخاص (صورة أو PDF) قبل الإكمال.
- قراءة الوردية الحالية وبدء الوردية وإنهاؤها.

## ملاحظات قبل الإنتاج

- هذا تطبيق ويب مستقل مبدئي، وليس تطبيق Android/iOS منشورًا.
- استخدم HTTPS في الإنتاج، وقيّم آلية حفظ التوكن وفق بيئة النشر؛ لا تضع التوكن في عنوان URL.
- يحتاج النشر إلى إعداد CORS وبيئة API، واختبارات متكاملة فعلية، وسياسة احتفاظ بملفات الإثبات وفحصها ضد البرمجيات الضارة.
- الواجهة لا تعرض ملفات الإثبات المحفوظة ولا تمنح صلاحية الوصول إلى مهام غير مسندة للسائق؛ يفرض API التحقق من الإسناد.
