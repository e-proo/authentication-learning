# اللوجستر — المكاتب التشغيلية

واجهة ويب عربية مستقلة لموظفي العمليات. لا تدمج واجهة السائق أو المستودع فيها؛ تتعامل هذه الواجهة مع APIs الحالية لإدارة المؤسسة والرحلات ومهام التوصيل والسائقين.

## التشغيل محليًا

المتطلبات: Node.js 20.19+ أو 22.12+، وخادم Laravel API يعمل مع حساب له عضوية نشطة وصلاحيات مناسبة.

```powershell
cd apps/operations-office
Copy-Item .env.example .env
npm install
npm run dev
```

عدّل `VITE_API_BASE_URL` في `.env` إلى عنوان API، ثم افتح عنوان Vite المحلي.

## الوظائف الموجودة في هذه النسخة

- تسجيل الدخول والخروج.
- اختيار المؤسسة من عضويات المستخدم المسموح بها.
- عرض ملخص الرحلات ومهام التوصيل.
- استعراض الرحلات والسائقين والمهام ضمن المؤسسة المختارة.
- إنشاء مهام استلام وتوصيل وربطها بالشحنات أو طلبات الإرجاع.
- البحث في المهام المعروضة، والتنقل بين صفحات المهام والرحلات، وعرض سجل أحداث المهمة وتفاصيل الموقع والمستلم.
- إسناد مهمة إلى سائق وربطها برحلة مسندة إلى السائق نفسه.
- إنشاء رحلة وإسنادها إلى سائق ومركبة، وتنفيذ إجراءات المغادرة والإكمال والإلغاء.

## حدود النسخة الحالية

هذه نسخة تشغيلية أولية وليست إعلانًا عن اكتمال المنتج النهائي أو نشره. قوائم الرحلات والمهام تدعم التنقل بين الصفحات، بينما البحث والتصفية الحاليان يطبّقان على العناصر المحمّلة في الصفحة الحالية. الصلاحيات النهائية يفرضها API. إنشاء الشحنات وإدارة المستودعات يبقيان ضمن واجهات مستقلة. يلزم نجاح البناء والاختبارات، واختبارات end-to-end، وإعداد HTTPS/CORS قبل الإنتاج.
