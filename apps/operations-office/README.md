# اللوجستر — المكاتب التشغيلية

واجهة ويب عربية مستقلة لموظفي العمليات. لا تدمج واجهة السائق أو المستودع فيها؛ تتعامل هذه الواجهة مع APIs الحالية لإدارة المؤسسة والرحلات ومهام التوصيل والسائقين.

## التشغيل محليًا

المتطلبات: Node.js 20.19+ أو 22.12+، وخادم Laravel API يعمل مع حساب له عضوية نشطة وصلاحيات مناسبة.

```powershell
cd apps/operations-office
Copy-Item .env.example .env
npm install
npm run dev
```

عدّل `VITE_API_BASE_URL` في `.env` إلى عنوان API، ثم افتح عنوان Vite المحلي.

## الوظائف الموجودة في هذه النسخة

- تسجيل الدخول والخروج.
- اختيار المؤسسة من عضويات المستخدم المسموح بها.
- عرض ملخص الرحلات ومهام التوصيل.
- استعراض الرحلات والسائقين والمهام ضمن المؤسسة المختارة.
- إسناد مهمة إلى سائق، وإسناد رحلة إلى سائق ومركبة.
- تنفيذ إجراءات المغادرة والإكمال والإلغاء للرحلات.

## حدود النسخة الحالية

هذه نسخة ويب أولية، وليست نظام مكاتب مكتملًا أو تطبيقًا منشورًا. الصلاحيات النهائية يفرضها API. لم تتم إضافة إنشاء الشحنات أو إدارة المستودعات هنا. يلزم اختبار CI واختبارات end-to-end وإعداد HTTPS/CORS قبل الإنتاج.
